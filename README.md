Мощный калькулятор с поддержкой 128-битной десятичной арифметики и удобным интерфейсом на Qt/QML.

Подходит для точных вычислений с большим диапазоном значений и позволяет работать с дробными числами, историей операций, корнями, факторизацией и генерацией случайных чисел.

## ✨ Возможности

- ✅ Разделитель тысяч
- ✅ Регулируемое количество знаков после запятой от 0 до 18
- ✅ История операций
- ✅ Отображение текущей операции и первого операнда во вспомогательном поле
- ✅ Повторное выполнение текущей операции, включая длительное нажатие Enter
- ✅ Горячее редактирование текущего числа с помощью курсора ввода
- ✅ Поддержка работы с большими числами: 128-бит целой части

## ⚙️ Основные особенности

- Смена знака числа осуществляется вводом `Shift + -`
- Количество знаков после запятой задаётся через `Ctrl + S`
- Нажатие `Esc` или кнопки `C` полностью сбрасывает калькулятор
- Поддерживаются базовые операции: сложение, вычитание, умножение и деление
- Реализовано правило округления всех девяток, благодаря чему в некоторых случаях корень вычисляется «точно» в смысле обратимости операции
- Интерфейс построен с использованием технологии QML

## 📊 Характеристики Decimal 128

### Диапазон значений

| Параметр | Значение |
|----------|----------|
| **Целая часть (максимум)** | 2^128 - 1 = 340,282,366,920,938,463,463,374,607,431,768,211,455 |
| **Целая часть (минимум)** | -(2^128 - 1) |
| **Дробная часть (точность)** | до 18 знаков после запятой |

### Разрядность

- **Целая часть:** 128 бит без знака
- **Дробная часть:** до 18 десятичных разрядов
